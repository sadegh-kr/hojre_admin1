## درباره تصویر سایدبار

تصویر `hojreh-sidebar-art.png` از بخش بالایی تصویر **۱۸۷×۲۵۴** ارسال‌شده شما، به ابعاد **۱۸۷×۲۰۱** بریده شده است. تصویر پایین سایدبار صرفاً تزئینی است. دکمه خروج باید از همان `Sidebar.vue` واقعی و با منطق فعلی کار کند؛ بنابراین دکمه داخل اسکرین‌شات همراه عکس کپی نشده است. به‌دلیل رزولوشن محدود، برای بزرگ‌نمایی بیش از عرض طبیعی مناسب نیست.

## ادغام بدون ریسک

۱. از Git یک commit یا backup امن بگیرید. ۲. فایل‌های CSS/Component بسته را در `hojre_admin/src` به مسیرهای مشخص منتقل کنید. ۳. **کد فعلی Dashboard.vue را پاک نکنید**؛ تنها template و CSS را با ظاهر مرجع تطبیق دهید. ۴. در `MainLayout` موجود فقط یک Sidebar و یک Header استفاده شود؛ اگر از `HojrehDashboardPro` استفاده می‌کنید `showShell=false` بماند. ۵. فایل `hojreh-vazirmatn.css` را یک‌بار در نقطه ورود CSS سراسری import کنید یا declarationهای آن را در `admin.css` ادغام کنید؛ هر دو راه را با هم انجام ندهید. ۶. در سایدبار اصلی عکس را بالای دکمه خروج واقعی قرار دهید.

**نباید** به Django، مدل‌ها، migration، دیتابیس، JWT، API، درخواست‌ها، Pinia، مسیرها، منطق سفارش‌ها و مجوزهای مالی دست زده شود.

## محدودیت

فایل‌های فونت از ویندوز شما در این محیط قابل خواندن نیستند، بنابراین کیت فقط مسیر آن‌ها را تعیین می‌کند. تصویر مرجع با هوش مصنوعی تولیدشده است و فایل CSS/فونت اصلی قابل استخراج دقیق نیست. کد هدف **بازسازی نزدیک** است، نه تطبیق پیکسلی تضمینی. build نهایی باید در ریپوی زنده شما اجرا شود؛ پیش‌نمایش HTML صرفاً نمونه است.
